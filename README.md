# Representing Document Concepts

This project aims to explore and evaluate different text embedding methods for representing and clustering Reddit posts. The study focuses on understanding how various embedding configurations influence clustering performance and semantic separability.

## Features
- Doc2Vec Embeddings
- Embeddings based on Word2Vec and Bag-of-Words
- Comparative Analysis

## Usage

Create and activate a virtual environment:  
`python -m venv venv`  
`source venv/bin/activate`  

Install dependencies:  
`pip install -r requirements.txt`  

Run Doc2Vec Embedding script:  
`python doc2vec.py`
